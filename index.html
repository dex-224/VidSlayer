Step 1
Enter a keyword or topic phrase
Type a short keyword or topic into the input at the top — like "burning fat", "morning routine", or "money mistakes". VidSlayer uses this to generate title ideas, a script outline, tags, and more. Press Enter or click "Generate All."
💡
Keep it short: 1–4 words works best. "burning fat" → generates titles like "3 Burning Fat Secrets That Feel Like CHEATING" and "How to Achieve Burning Fat in 30 Days Without the Guesswork."
✍️
Keyword vs. Title — what's the difference?
Keyword = the core topic. Enter this in the main input to generate everything.
Examples: burning fat · morning routine · money mistakes · YouTube growth

Title = the full clickable video title. Paste this into the CTR Title Score card after picking one from the Title Variations section — to see how it scores.
↻
Keyword change = auto-update: After generating, editing the keyword automatically regenerates the script outline after you stop typing — no need to click "Generate All" again.

Step 3
Generate your script with AI
Inside the Script Outline card, adjust the word count slider (default: 1,500 words), then copy the prompt and paste it into Claude, ChatGPT, or any AI. The prompt tells the AI to research the topic first, then write a full script following the outline.
🤖
What's inside the AI prompt?
1. Research first — looks up facts, stats, and examples before writing a word
2. Follows the outline — uses the exact structure VidSlayer generated
3. Conversational tone — like talking to one close friend
4. BUT/THEREFORE transitions — keeps viewer retention high
5. Teleprompter-ready — each sentence on its own line, no stage directions
📝
Word count slider: 500 words ≈ 4 min  ·  1,500 words ≈ 11 min  ·  5,000 words ≈ 38 min

Is VidSlayer really free?▼
Yes, completely. VidSlayer runs entirely in your browser — no server, no database, no API calls. No sign-up, no credit card, no free trial. Everything is free forever.
Do I need an account or API key?▼
No. VidSlayer has no accounts and requires no API key. All tools run locally in your browser using JavaScript — nothing is sent to any server.
Why use an AI prompt instead of generating the script directly?▼
Generating a full 1,500+ word script requires a large language model — which needs an API key and costs money per request. By giving you a ready-to-paste prompt, VidSlayer stays completely free while still getting great results from Claude, ChatGPT, or any AI you already use.
Which AI should I paste the script prompt into?▼
Claude (claude.ai) or ChatGPT both work great. Claude tends to write more conversational, natural-sounding scripts. Both have free tiers. Paste the copied prompt, hit send, then paste the result back into VidSlayer's Script Studio.
Can I use a script I wrote myself or made somewhere else?▼
Absolutely. Script Studio works with any script from any source — AI-generated, hand-written, from Google Docs, Notion, Word, or anywhere else. Paste it in and click "Generate from Script." If your script starts with the topic on the first line, VidSlayer will extract it and use it across all sections.
What does the CTR score actually measure?▼
The CTR score checks your title against proven factors: length (40–55 chars is ideal), numbers, curiosity-gap language, power words, question format, brackets, year signals, CAPS emphasis, and benefit framing. It's a guide, not a guarantee — but titles scoring 70+ consistently outperform lower-scoring ones.
Why should thumbnail text complete the title, not repeat it?▼
The best-performing thumbnails tell a different part of the story. If your title is "I Quit My 6-Figure Job" — your thumbnail shouldn't repeat that. Say "BEST DECISION EVER" or "BIGGEST MISTAKE" instead — so together they create one bigger, more compelling story that makes people click.
Can I use VidSlayer on my phone?▼
Yes. VidSlayer is fully responsive and works on mobile browsers. The layout adjusts to a single column on smaller screens, and all copy buttons work on iOS and Android.
