Frequently asked questions

Click a question to expand.

Is VidSlayer really free?▼
Yes, completely. VidSlayer runs entirely in your browser — no server, no database, no API calls. No sign-up, no credit card, no free trial. Everything is free forever.
Do I need an account or API key?▼
No. VidSlayer has no accounts and requires no API key. All tools run locally in your browser using JavaScript — nothing is sent to any server.
Why use an AI prompt instead of generating the script directly?▼
Generating a full 1,500+ word script requires a large language model which needs an API key and costs money per request. By giving you a ready-to-paste prompt, VidSlayer stays completely free while still getting great results from Claude or ChatGPT.
Which AI should I paste the script prompt into?▼
Claude (claude.ai) or ChatGPT both work great. Claude tends to write more conversational, natural-sounding scripts. Both have free tiers.
Can I use a script I wrote myself or made somewhere else?▼
Absolutely. Script Studio works with any script from any source — AI-generated, hand-written, from Google Docs, Notion, Word, or anywhere else.
What does the CTR score actually measure?▼
The CTR score checks your title against proven factors: length (40–55 chars is ideal), numbers, curiosity-gap language, power words, question format, brackets, year signals, CAPS emphasis, and benefit framing.
Why should thumbnail text complete the title, not repeat it?▼
The best-performing thumbnails tell a different part of the story. If your title is "I Quit My 6-Figure Job" — say "BEST DECISION EVER" on the thumbnail instead, so together they create a more compelling story.
Can I use VidSlayer on my phone?▼
Yes. VidSlayer is fully responsive and works on mobile browsers. The layout adjusts to a single column on smaller screens, and all copy buttons work on iOS and Android.
